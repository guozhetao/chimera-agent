# Archive

This directory keeps historical scripts and documents that are not part of the current GARF-H pipeline. They are provided for provenance and are not maintained.

- `legacy_scripts/` — earlier plotting, analysis and task-comparison scripts. They may reference old result layouts and old model APIs.
- `docs/archive/` — the original analysis workflow document.

For the current pipeline use `README.md`, `docs/PROJECT_REPORT_CN.md`, `docs/OPTIMIZATION_REPORT.md`, `docs/BENCHMARK.md` and the scripts in `scripts/`.
